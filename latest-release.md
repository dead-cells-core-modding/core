# Release Notes - 35.13.8

## Feature

- DCCMShell: refined the Chinese error report prompt to guide users to send the log file instead of a photo or screenshot of the window.

## Fix

- HaxeProxy: custom Haxe type inheritance now skips methods that are missing from the native prototype instead of throwing, avoiding failures when an inherited method is not present.

# 更新说明

## Feature

- DCCMShell：改进了中文错误报告提示，引导用户发送日志文件，而不是发送窗口的照片或截图。

## Fix

- HaxeProxy：自定义 Haxe 类型继承现在会跳过原生原型中不存在的方法，不再抛出异常，避免因缺失继承方法而导致失败。
