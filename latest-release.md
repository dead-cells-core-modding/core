# Release Notes - 35.12.4

## Feature

- Error reports now include detailed system specifications (OS, CPU, memory, GPU) to aid in diagnosing issues, supported on both Windows and Linux platforms.
- Native Steam library extraction now skips re-extraction when the existing file already matches the embedded resource, reducing unnecessary disk I/O on every launch.

# 更新说明 - 35.12.4

## 新增功能

- 错误报告现在包含详细的系统规格信息（操作系统、CPU、内存、GPU），以帮助诊断问题，支持 Windows 和 Linux 平台。
- 原生 Steam 库文件提取现在会在现有文件已与嵌入资源匹配时跳过重复提取，减少每次启动时不必要的磁盘 I/O。
